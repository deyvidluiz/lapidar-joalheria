# Lapidar Joalheria

Site de vitrine para joalheria: diamante interativo, catálogo com filtro, sacola com finalização pelo WhatsApp e guia de aros.

É uma única página (`index.html`), sem build. Para ver, abra o arquivo no navegador ou publique com GitHub Pages.

## Personalizar

No final do `index.html`, no início do `<script>`:

- `LOJA` — nome, número do WhatsApp (só números, com 55 e DDD) e telefone exibido.
- `PRODUTOS` — nome, categoria, material, preço e etiqueta de cada peça.
